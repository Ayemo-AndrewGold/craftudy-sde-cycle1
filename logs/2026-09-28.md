## Key Concepts

### 1. JavaScript Runtime Environment

A runtime environment provides the facilities required to execute JavaScript code.


* JavaScript is the programming language.
* V8 is the JavaScript engine used by Node.js.
* Node.js provides the runtime environment and additional APIs for server-side development.

### 2. Node.js vs Browser JavaScript

| Browser JavaScript                    | Node.js                                  |
| ------------------------------------- | ---------------------------------------- |
| Runs inside a browser environment     | Runs outside the browser                 |
| Provides browser APIs such as the DOM | Provides APIs such as `fs` and `process` |
| Commonly handles user interactions    | Commonly handles server-side operations  |

### 3. Node.js Project Setup

Initialize a project:

```bash
npm init -y
```

Execute a JavaScript file:

```bash
node app.js
```

Run the application through an npm script:

```bash
npm start
```
